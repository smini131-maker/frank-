# 제24회 임베디드SW경진대회 개발완료보고서 초안

> 최종 제출 전 `<부문>`, `<팀번호_팀명>`, YouTube 링크를 실제 값으로 교체한다.

## 1. 개발 개요

- 작품명: 시각장애인 및 저시력자를 위한 AI 인식 기반 선택 개방형 스마트 분리수거함
- 개발 배경: 기존 분리수거함은 사용자가 표기와 투입구 위치를 시각적으로 확인해야 하므로 시각장애인과 저시력자에게 접근성 제약이 있다.
- 개발 목표: 쓰레기 종류를 AI로 판별하고 음성으로 안내한 뒤 해당 분류 칸만 자동 개방하여 비시각적 분리배출을 지원한다.
- 소스코드: https://github.com/smini131-maker/frank-/tree/smart-bin-contest
- 시연 동영상: `<YouTube 링크>`

## 2. 개발 환경

Raspberry Pi 5, Camera Module 3, PCA9685, MG90S 서보모터 4개, HC-SR501 계열 PIR 센서, RS-50-5 5V 10A SMPS, USB 오디오 장치를 사용한다. Python 3.11, OpenCV, TensorFlow Lite Runtime, gpiozero/lgpio, Adafruit ServoKit, ALSA `aplay`를 사용한다. systemd 서비스로 등록하여 노트북과 인터넷 없이 독립 실행한다.

## 3. 개발 프로그램 설명

1. 카메라 노출 안정화 및 기준 배경 수집
2. ROI 배경 차분과 연속 프레임 조건으로 물체 진입 확인
3. 1차 6분류 모델 추론
4. PET/플라스틱 후보에 한해 2차 전문 모델 추론
5. 결과 WAV 안내
6. 해당 분류 칸의 서보만 개방 후 자동 폐쇄
7. 동일 물체 LOCK 및 제거 확인 후 대기 상태 복귀

## 4. 장애요인과 해결방안

- 투명 PET와 일반 플라스틱의 혼동: 2차 전문 분류기를 추가하였다.
- 작은 물체의 낮은 화면 변화율: 진입 변화율 임계값을 조정하고 연속 프레임 판정을 유지하였다.
- PIR 전원 직후 오감지와 반복 안내: 안정화 시간과 1회 안내 제어를 적용하였다.
- 서보 전원 불안정: 외부 5V SMPS와 공통 접지를 사용하였다.
- SSH 종료 시 프로그램 종료: systemd 부팅 자동 실행으로 독립 운용하도록 변경하였다.
- 동일 물체 반복 인식: LOCKED/CLEARING 상태를 도입하였다.

## 5. 차별성

- 단순 분류 결과 표시가 아니라 해당 투입구만 물리적으로 개방한다.
- 시각 정보에 의존하지 않는 음성 중심 사용자 경험을 제공한다.
- 1차 범용 모델과 2차 PET/플라스틱 전문 모델을 결합한다.
- 클라우드 없이 엣지 장치에서 오프라인 추론한다.

## 6. 파급력 및 기대효과

공공시설, 학교, 복지시설, 교통시설 등에 적용하여 분리배출 접근성과 정확도를 높일 수 있다. 향후 분류 항목 확대, 투입량 감지, 관리 서버 연동, 다국어 안내로 발전시킬 수 있다.

## 7. 개발 일정 및 업무 분장

아이디어 구체화 → 데이터 수집·정제 → 1차 모델 학습 → 2차 전문 모델 학습 → 카메라 상태 머신 → 서보·오디오·PIR 통합 → 기구물 보정 → systemd 독립 실행 → 시연 촬영 및 보고서 작성 순으로 진행하였다. 실제 참가 인원과 팀 정보는 최종 보고서에 기입한다.
